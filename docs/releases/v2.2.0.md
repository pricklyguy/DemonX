# DemonX 2.2.0

DemonX controls a machine that can hurt you and wreck work. Keep a hand near the machine's emergency stop and run a new program in
the air first.

**This release adds the CNC tab's toolpaths to DemonX Design.** DemonX (the CNC controller) is the same as 2.1.1. Design makes
G-code files for you to run; nothing in this release sends a command to a machine by itself. **No toolpath here has been cut on a
real machine.** Run the first one of each kind in the air, slowly, with the emergency stop in reach.

## What's new since 2.1.1 (DemonX Design, CNC tab)

- **Toolpath icons and a setup panel.** Each toolpath kind has an icon with hover text. The setup opens as a panel on the far right,
  full height, with its options stacked (cutting depths, tool, machine vectors, direction, safe Z, vector selection, name). Press
  **Calculate** to make the toolpath, or **Cancel** (Escape too).
- **Preview and simulation.** Preview all, Preview selected, Reset preview, Save preview image (a PNG), and an animated **Simulate**
  with a tool marker, a slider, Pause, speeds 0.5x to 10x and a readout of depth and percent. Colours for the cut, the travel and the
  material are kept in the browser.
- **New toolpaths:**
  - **Engraving:** follows the selected lines and outlines themselves, open or closed (text too), at the cut depth.
  - **V-bit carving:** carves the inside of closed shapes, deeper where the shape is wider, down to the max depth you set.
  - **Inlay:** a pocket, a mating plug and (if ticked) the plug's cut-out, in one step. The plug and its cut-out are mirrored by
    default. Mirror is also a setting of any toolpath.
  - **Photo:** lines (depth follows brightness) or dots (a hole as deep as it is dark) from a picture, with width, invert, spacing
    and a cap of 400,000 moves.
  - 3D roughing and 3D finishing are shown but not made yet.
- **DemonX post processors built in:** Genmitsu Cubiko (mm), Baby CNC 3018 (mm), DemonCarve Vacuum M2 (mm) and DemonCarve PCB (mm),
  as supplied, after the two generic ones in the list.
- **Tool library.** The **Library** icon opens it as a panel: search by name, part number or maker; filter by machine and material;
  "only tools ready for a job"; fill in a missing kind, diameter, V-bit angle or flutes right there. **Add to job with this recipe**
  brings the cutter in with that recipe's rpm, feed, plunge, depth per pass and stepover; a recipe that is not approved says so, and
  one without speed, feed and plunge cannot be used. **Add to job (no recipe)** uses cautious numbers. **Load library file...** merges
  a file and **Save a copy** writes `tool-library.json`. The library is kept on the Design computer (`data/tool-library.json`) and in
  each browser as a copy. `scripts/library-from-sqlite.py` builds the file from the shop's database (read only).
- **Saved files.** A file with an engraving, V-carve, plug, mirrored or photo toolpath **will not open in an older Design**. Older
  files open unchanged.

## Download

| You have | Get |
|---|---|
| Windows 10 or 11 | **`DemonX-2.2.0-windows-x64.zip`** (below, with its `.sha256` checksum file, which Update now needs), or Update now from 2.0.1 or later if you turned it on. A fresh install: extract to `C:\`, double-click `Start DemonX.bat`, and `Start DemonX Design.bat` for Design. `READ ME FIRST.txt` explains everything. |
| Raspberry Pi | `docs/RASPBERRY-PI.md` in the source; `./scripts/update.sh` (or Update now) updates DemonX, and Design too where it is set up under PM2 |
| Linux or macOS | `docs/LINUX-MAC.md` in the source |

After updating, hard-refresh the browser (Ctrl+Shift+R) so the new look and Design's fixes load. Your `design.env` and `design/data/`
stay where they are. DemonX Design on Windows is a separate window and keeps running the old version until you close it and start it
again. On a Raspberry Pi, Update now restarts Design only when it is idle.

## What has been tested

- DemonX's tests (509) and Design's tests, and typecheck for both. The Checks run on every change in this release was green.
- Design's browser checks against the simulator for each new part: the toolpath icons, preview, engraving, V-carve, inlay, photo, and
  the tool library.
- **Not tested on hardware. Not one of these toolpaths has been cut.** The G-code, the posts (including the four DemonX ones) and the
  tool-library recipes have only been checked by tests and the simulator. Check the first cut of each kind in the air.
- **Not done yet** (from the plan notes): V-bit depth that follows a shape with an exact middle line, a flat-bottom clear with a second
  tool, lead in and out, tabs and ramps, the cut shown as removed material, and 3D roughing and finishing.
- Everything listed as not tested on real hardware in the 2.0.2 and 2.0.1 notes still applies. HTTPS: the PIN and the page travel
  unencrypted on your network. Do not expose DemonX or Design to the internet.
