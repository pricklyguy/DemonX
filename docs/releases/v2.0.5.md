# DemonX 2.0.5

DemonX controls a machine that can hurt you and wreck work. Keep a hand near the machine's emergency stop and run a new program in
the air first.

**This release changes DemonX Design only (drawing tools).** DemonX (the CNC controller) is the same as 2.0.4, and nothing here
sends a command to a machine.

## What's new since 2.0.4 (DemonX Design)

- **Type text on the drawing.** The Text tool puts a blinking cursor where you click. Type, Enter for a new line, and the letters are
  drawn as you type. The bar above sets Font, Height, Alignment, Spacing, Lines, Curve and Welded. Ctrl+Enter, Place or a click on the
  drawing puts it in; Escape drops it. **Double-click** text (anywhere in its box) to type over it where it stands.
- **Curve handle on text.** Pick text and drag the small "curve" square above it: up for an arch, down for a smile. The text stays
  editable (the Curve box sets the angle exactly) and the bend follows moves, scales and saving.
- **System fonts.** "System fonts..." in the Text dialog lists the fonts installed on the computer. Chrome or Edge only, on a page
  opened as localhost or over https, after you allow it. On a plain http address on the network the button is off and says why;
  a font file still works.
- **Fillet tool (B).** Click a corner to round it, or click the ends of two separate lines: they are extended (or cut back) to meet,
  joined and rounded in one step. Round, scoop or chamfer.
- **Boundary and Extend.** Boundary outlines the selected shapes (per touching group, per shape, or one convex outline, with a gap).
  Extend pulls two open lines to where they meet.
- **Check vectors.** Lists shapes that cross themselves, outlines that cross, open lines, nearly closed lines, stacked points, specks
  and duplicates. Show picks them. **Fix** closes nearly closed lines, cleans points and deletes specks and duplicates; crossings and
  open lines are only reported.
- **Fit curves.** Smooths many-point lines (traced or imported) into curves with far fewer points; corners are kept.
- **Import bitmap and trace.** PNG, JPEG, GIF, WebP or BMP, with a live black and white preview, threshold (auto), specks, smoothing
  and width in mm. Holes and corners are kept; undo takes it back in one step.
- **Keyboard shortcuts you can change.** The gear in File Operations lists every tool and edit key. A key that is taken leaves its old
  action with none and says so. The tool bar follows.
- **Polish.** The circle's box says Diameter. Ctrl+V pastes with the copy's middle under the pointer (over the drawing). Group and
  ungroup have hub icons, and a thin bar separates Copy, Paste, Cut, Duplicate and Delete from the tools above.
- Design files gain an optional list of texts (now with a bend); older files open unchanged.

## Download

| You have | Get |
|---|---|
| Windows 10 or 11 | **`DemonX-2.0.5-windows-x64.zip`** (below, with its `.sha256` checksum file, which Update now needs), or Update now from 2.0.1 or later if you turned it on. A fresh install: extract to `C:\`, double-click `Start DemonX.bat`, and `Start DemonX Design.bat` for Design. `READ ME FIRST.txt` explains everything. |
| Raspberry Pi | `docs/RASPBERRY-PI.md` in the source; `./scripts/update.sh` (or Update now) updates DemonX, and Design too where it is set up under PM2 |
| Linux or macOS | `docs/LINUX-MAC.md` in the source |

After updating, hard-refresh the browser (Ctrl+Shift+R) so Design's new tools load. Your `design.env` and `design/data/` stay where
they are. DemonX Design on Windows is a separate window and keeps running the old version until you close it and start it again.
On a Raspberry Pi, Update now restarts Design only when it is idle.

## What has been tested

- Design's tests (479) and its browser checks for every new tool above, plus the older Design checks, all against the simulator.
- **Not tested on hardware: this release is drawing-side only.** Nothing in it sends a command to a machine.
- **System fonts were not tried with real installed fonts.** Headless Chromium has none, so the check uses a stand-in for the
  browser feature.
- Everything listed as not tested on real hardware in the 2.0.2 and 2.0.1 notes still applies (the Laser tab's new moves, Home, Z and
  Auto focus, Pause and Resume, the Windows updater and package, and the rest). HTTPS: the PIN and the page travel unencrypted on
  your network. Do not expose DemonX or Design to the internet.
