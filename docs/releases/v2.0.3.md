# DemonX 2.0.3

DemonX controls a machine that can hurt you and wreck work. Keep a hand near the machine's emergency stop and run a new program in
the air first.

**This release changes DemonX Design only (drawing tools).** DemonX (the CNC controller) is the same as 2.0.2, and nothing here
sends a command to a machine.

## What's new since 2.0.2 (DemonX Design)

- **A new tool bar**, four icons wide and grouped as in VCarve: File Operations, Create Vectors, Edit Objects, Offset and Layout.
  The **Grid** and **Points** snap boxes are pinned at its top so they cannot be pushed out of sight. New, Open, Save and Import
  vector are on the bar (Import bitmap is shown but not available yet).
- **Draw Circle card**: Diameter (the default) or Radius, centre X and Y, Create and Close. With the card open, **each click on the
  drawing puts a circle of that size there**, again at every click; a drag still sizes one by hand.
- **Draw Rectangle card**: width, height, a nine-dot reference point, X and Y, with the same click-to-place.
- **New Ellipse, Polygon (any number of sides), Star and Arc tools** with the same kind of card and click-to-place. They become
  ordinary paths, so they offset, trim and cut like anything else.
- The sizes and choices you make in the cards are remembered in the browser.
- The icon pictures are rough and will be redrawn. Not in this release: an Alignment pop-out, move and resize, text editing, and a
  vector validator.

## Download

| You have | Get |
|---|---|
| Windows 10 or 11 | **`DemonX-2.0.3-windows-x64.zip`** (below, with its `.sha256` checksum file, which Update now needs), or Update now from 2.0.1 or later if you turned it on. A fresh install: extract to `C:\`, double-click `Start DemonX.bat`, and `Start DemonX Design.bat` for Design. `READ ME FIRST.txt` explains everything. |
| Raspberry Pi | `docs/RASPBERRY-PI.md` in the source; `./scripts/update.sh` (or Update now) updates DemonX, and Design too where it is set up under PM2 |
| Linux or macOS | `docs/LINUX-MAC.md` in the source |

After updating, hard-refresh the browser (Ctrl+Shift+R) so Design's new tool bar loads. Your `design.env` and `design/data/` stay where
they are. DemonX Design on Windows is a separate window and keeps running the old version until you close it and start it again.

## What has been tested

- Design's tests and its browser checks for the shapes, the tool bar, tabs, menus and copy and paste, all against the simulator.
- **Not tested on hardware: this release is drawing-side only.** Nothing in it sends a command to a machine.
- One of Design's browser checks, `design/e2e/design.mjs`, fails at its GRBL Pause step. It fails the same way before these changes,
  so it is not caused by them; its cause has not been looked into.
- Everything listed as not tested on real hardware in the 2.0.2 and 2.0.1 notes still applies (the Laser tab's new moves, Home, Z and
  Auto focus, Pause and Resume, the Windows updater and package, and the rest). HTTPS: the PIN and the page travel unencrypted on
  your network. Do not expose DemonX or Design to the internet.
