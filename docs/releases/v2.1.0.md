# DemonX 2.1.0

DemonX controls a machine that can hurt you and wreck work. Keep a hand near the machine's emergency stop and run a new program in
the air first.

**This release changes how DemonX looks and fixes some of DemonX Design's drawing tools.** DemonX (the CNC controller) changes only in
its header; nothing here changes how any machine is moved or sent a command. This is also the first release where all the work is on
one branch (`main`).

## What's new since 2.0.5

- **New look.** The DX mark, the favicon (16 to 512 px and an .ico) and a wordmark in each header: "DemonX CNC" in the controller and
  "DemonX Design" in Design. The old Prickly Guy logo is gone from the headers.
- **Design, text:** Ctrl+Enter and Escape now work from the bar above the text as well as from the text box (the confirming Enter is
  no longer typed into the text). This fixes the Spacing box swallowing Ctrl+Enter. The Text tool no longer goes quiet when the font
  it remembered is not installed.
- **Design, Fillet:** an outline that repeats its first point now has its start corner rounded too, the card says what a click did,
  and the group and ungroup icons are clearer.

## Download

| You have | Get |
|---|---|
| Windows 10 or 11 | **`DemonX-2.1.0-windows-x64.zip`** (below, with its `.sha256` checksum file, which Update now needs), or Update now from 2.0.1 or later if you turned it on. A fresh install: extract to `C:\`, double-click `Start DemonX.bat`, and `Start DemonX Design.bat` for Design. `READ ME FIRST.txt` explains everything. |
| Raspberry Pi | `docs/RASPBERRY-PI.md` in the source; `./scripts/update.sh` (or Update now) updates DemonX, and Design too where it is set up under PM2 |
| Linux or macOS | `docs/LINUX-MAC.md` in the source |

After updating, hard-refresh the browser (Ctrl+Shift+R) so the new look and Design's fixes load. Your `design.env` and `design/data/`
stay where they are. DemonX Design on Windows is a separate window and keeps running the old version until you close it and start it
again. On a Raspberry Pi, Update now restarts Design only when it is idle.

## What has been tested

- DemonX's tests (509) and Design's tests (481), and typecheck for both.
- Browser checks against the simulator for the CNC screen and Design (listed in the pull request).
- **Not tested on hardware: nothing in this release sends a command to a machine.** The CNC change is the header only.
- Everything listed as not tested on real hardware in the 2.0.2 and 2.0.1 notes still applies (the Laser tab's new moves, Home, Z and
  Auto focus, Pause and Resume, the Windows updater and package, and the rest). HTTPS: the PIN and the page travel unencrypted on
  your network. Do not expose DemonX or Design to the internet.
