# DemonX 2.0.0-test.1 — first test release

**This is a test release for volunteers.** DemonX controls a machine that can hurt you and wreck work. Keep a hand near the
machine's emergency stop, run a new program in the air first, and read "What has not been tested" below.

DemonX is a browser-based CNC controller by Prickly Guy Creations. One computer is connected to the machine; any browser on
your network (a laptop, a phone, a touchscreen) shows and controls the same machine. It works with **GRBL** and **FluidNC**
controllers.

## Download

| You have | Get |
|---|---|
| Windows 10 or 11 | **`DemonX-2.0.0-test.1-windows-x64.zip`** (below). Unzip to `C:\`, double-click `Start DemonX.bat`. Everything needed is inside, including `READ ME FIRST.txt`. |
| Raspberry Pi | `docs/RASPBERRY-PI.md` in the source |
| Linux or macOS | `npm install && npm run build && npm start`, then open http://localhost:8080 |

Try it with no machine: type `simulator` in the Connection panel's port box.

## What it does

- **Run a machine from any browser:** live position, jog, zero, home, unlock, overrides, console, job load/start/pause/stop. The
  server owns the connection and streams at full speed; any number of browsers can watch.
- **Probing with safety checks:** Z, PCB-surface Z, and 3-axis XYZ block probes. Every probe asks "is the probe connected?"
  before it moves and "remove the probe" afterwards, enforced on the server so no other browser or macro can get around it.
- **Autolevel for PCB milling:** scan the board, then DemonX writes a *new levelled G-code file* you can inspect and run. A file
  it cannot level correctly is refused with the line number rather than run partly levelled.
- **PCB mode:** a fixture position and a safe height, a PCB Home that goes to the same spot every time, and a checklist
  (home, set Z0, scan, load G-code, apply the map). Normal Home is turned off while it is on.
- **3D visualizer, macros, spindle panel, controller settings:** read and change GRBL `$` settings or a FluidNC `config.yaml`
  (with a backup of the old config), macros that cannot bypass the probe safety, spindle buttons and speeds you choose.
- **Cameras:** Home Assistant (smooth video), Reolink, web camera, RTSP (needs ffmpeg), or a direct address.
- **Access PIN:** one PIN limits who can control the machine. A phone or laptop without it can only watch. The computer that
  runs DemonX never needs it, and "Remember this device" keeps others signed in.
- **Home Assistant:** the machine appears as a device through MQTT (state, X/Y/Z, feed, spindle, job progress, elapsed and
  remaining time, alarm...) with six buttons: Home, Unlock, Reset, Feed Hold, Resume, Stop. Nothing else can be controlled from
  there. Events such as `demonx_job_finished` can trigger automations.
- Touch-friendly layout you can rearrange, dark and light themes, millimetres or inches, your own colours.

## What has been tested on real machines

By the project owner, on two machines:

- **A large FluidNC router** (Dobermann S3 board): connection, jog, home, a job run in the air, remote viewing, Z/PCB/XYZ
  probing, autolevel scan and file generation, controller settings (read, apply, save, backup), Home Assistant camera.
- **A small plain-GRBL PCB mill** (Raspberry Pi): connection, jog, home, spindle, PCB mode and PCB Home, PCB Z probing,
  an autolevel scan, the levelled file, and a small PCB cut that came out well.
- **Windows laptop:** start, USB connection to a real machine, a phone connecting with the PIN, start at login, updating over an
  older install keeping the settings.
- **Home Assistant:** the MQTT device, its sensors and dashboard.

## What has not been tested

Please tell us how these go:

- A long cutting job run on a levelled file on the large router (the first cut results are not in yet).
- The **Frame** button, and the spindle panel's status line on FluidNC.
- Windows 10, other USB serial adapters, and what Windows shows for a zip downloaded from the internet (SmartScreen may warn:
  the start files are not signed).
- Other GRBL variants (grblHAL, GRBL 0.9, ESP3D boards), machines in inches (`$13`), G20 programs.
- macOS, and more than a couple of browsers at once.
- HTTPS: the PIN and the page travel unencrypted on your network. Do not expose DemonX to the internet.

## Known limits

- There is one shared PIN, no user accounts. HOLD, RESET and the other buttons need the PIN on a browser that has not signed in.
- The Windows package is not a Windows service: the computer has to be signed in.
- Remaining job time is an estimate from lines done, rough in the first minute.
- Autolevel refuses relative mode (G91), inches, R-format arcs, G92/G10/G28/G30, and non-XY planes. Rapid G53 moves (park or
  retract) are allowed.

## Reporting problems

Open an issue on GitHub with: what you did, what you expected, what happened, the controller (GRBL or FluidNC and its
version), your operating system, and the lines from DemonX's Console or the black window. Screenshots help.
