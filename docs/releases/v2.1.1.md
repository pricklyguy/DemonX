# DemonX 2.1.1

DemonX controls a machine that can hurt you and wreck work. Keep a hand near the machine's emergency stop and run a new program in
the air first.

**This release changes DemonX Design (the New design dialog and job setup) and tidies the DemonX layout presets.** Nothing here sends
a command to a machine, and nothing changes how a machine is moved.

## What's new since 2.1.0

- **A new "New design" dialog (Design).** It no longer offers made-up choices (built-in lasers, "Custom size", "No size limit"). It
  lists only the lasers you added and the setups you saved. Under **Setup new job**: Width (X) and Height (Y); job type CNC, Laser or
  Canvas; Thickness (Z) for CNC (required) and a laser (optional); for CNC, Single or Double sided, Z zero (material surface or machine
  bed) and the XY datum (four corners or the centre); S max and rapid for a laser; **Save this setup** with a name; **Create job**.
  Saved laser, CNC and canvas setups are lists you can open, close, remove (after "Sure?") and start from with a double-click or Open.
  The last numbers you used are remembered.
- **Canvas jobs (Design).** A canvas is a page of the size you give, drawn like a laser bed (0,0 bottom left), with **no machine
  output**: there is no laser or Ruida job and no CNC toolpath or G-code until you press **Make it a laser job** (Laser tab) or
  **Make it a CNC job** (CNC tab, with a Thickness box). Both keep every shape. The header says "(canvas)".
- **CNC sides (Design).** A CNC job is Single or Double sided. It is kept with the job and in the file and shown in the CNC panel.
  **The toolpaths do not use it yet.** The Work area dialog (header button) keeps it too.
- **Saved files.** `sides` is optional; a file with a `sides` value other than 1 or 2 is refused instead of being quietly changed.
  Files made before open unchanged. **A file with the new canvas job type will not open in an older Design** (it says the job type is
  not known).
- **DemonX layout presets.** The Overrides and Jog panels are now tall enough in the Run and Setup presets that they no longer show a
  scroll bar. Only the preset sizes changed, not the panels.

## Download

| You have | Get |
|---|---|
| Windows 10 or 11 | **`DemonX-2.1.1-windows-x64.zip`** (below, with its `.sha256` checksum file, which Update now needs), or Update now from 2.0.1 or later if you turned it on. A fresh install: extract to `C:\`, double-click `Start DemonX.bat`, and `Start DemonX Design.bat` for Design. `READ ME FIRST.txt` explains everything. |
| Raspberry Pi | `docs/RASPBERRY-PI.md` in the source; `./scripts/update.sh` (or Update now) updates DemonX, and Design too where it is set up under PM2 |
| Linux or macOS | `docs/LINUX-MAC.md` in the source |

After updating, hard-refresh the browser (Ctrl+Shift+R) so the new look and Design's fixes load. Your `design.env` and `design/data/`
stay where they are. DemonX Design on Windows is a separate window and keeps running the old version until you close it and start it
again. On a Raspberry Pi, Update now restarts Design only when it is idle.

## What has been tested

- DemonX's tests (509) and Design's tests, and typecheck for both, on every change that went into this release.
- Design's browser checks against the simulator, including new ones for the New design dialog and for canvas jobs.
- The layout presets with the DemonX browser check for layouts (34 of 34), at 1920 x 1080 and 1366 x 768.
- **Not tested on hardware: nothing in this release sends a command to a machine.** The Windows package and its `.bat` files have
  still not been run on Windows by the owner.
- Everything listed as not tested on real hardware in the 2.0.2 and 2.0.1 notes still applies (the Laser tab's new moves, Home, Z and
  Auto focus, Pause and Resume, the Windows updater and package, and the rest). HTTPS: the PIN and the page travel unencrypted on
  your network. Do not expose DemonX or Design to the internet.
