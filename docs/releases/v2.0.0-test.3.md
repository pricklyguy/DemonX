# DemonX 2.0.0-test.3

**Still a test release for volunteers.** DemonX controls a machine that can hurt you and wreck work. Keep a hand near the
machine's emergency stop and run a new program in the air first.

## What's new since 2.0.0-test.2

- **3D view knows the machine size.** A few seconds after connecting, DemonX reads the machine's travel from the controller
  (FluidNC's config, or GRBL's `$130`-`$132`), and the view and grid cover the whole machine until you load a G-code file, then zoom
  to the file. A **Machine** button pulls the view back. **Settings > Machine size** shows what was read and lets you type the
  size in (with "homes at the left/right, front/back, top/bottom") for a controller that does not report it. No more tool
  off screen on a large machine.
- **Hold to jog.** On the Jog panel a tap is one step and holding a button keeps the machine moving until you let go (mouse or
  pen). Keyboard shortcuts do the same (**Settings > Keyboard**, off by default; arrow keys, Page Up/Down, `[` `]` for the step,
  Space for feed hold, Esc to stop; every key can be changed). Holding a **finger** on a touch screen is optional (**Settings > Jog
  buttons**, off by default): it works and stops safely, but how smooth it is depends a great deal on the touch screen and the
  computer. Holds are stopped by the server on release, on silence, on a lost connection, on an alarm, and after 30 seconds or
  20 mm of Z.
- **Gamepad** (**Settings > Gamepad**, off by default): left stick X/Y, right stick Z, speed follows the stick. Press Start with
  the sticks centred to arm it; B stops. It disarms by itself if the page loses focus, the pad is unplugged, a job starts or the
  machine alarms.
- **Stats and maintenance** (**Settings > Stats & maintenance**): total running hours, jobs run, recent jobs, and maintenance
  tasks that come due after so many running hours (starter tasks you can edit). A dot on Settings shows when one is due. Home
  Assistant gets Machine Hours, Jobs Run, Next Maintenance and a Maintenance Due sensor.
- **Port dropdown** instead of the type-to-filter box (so "simulator" no longer hides the real ports).
- **Compact size setting** (Settings > Appearance): smaller buttons and fields.
- **Overrides panel** shows the current feed rate.
- Jog panel number and step fields are sized for a few digits instead of stretching across the panel.
- **Linux and macOS install guide** (`docs/LINUX-MAC.md`).

## What has been tested on real machines

By the project owner:

- **A large FluidNC router:** the machine size read from the controller (and shown in the 3D view), the port dropdown, hold to
  jog with the mouse and with the keyboard, the gamepad (a wired Xbox controller), and the optional finger hold on its touch
  screen (it works and stops safely, but moves in jerks at first and at random, which is why it is optional).
- Everything from 2.0.0-test.1 and 2.0.0-test.2 (see those notes).

## What has not been tested on real hardware

These are built and checked against the built-in simulator, but not yet tried on a real machine:

- Stats and maintenance (the hours over a real job, and the Home Assistant sensors), the Compact size setting, the feed rate in
  the Overrides panel, the typed-in machine size.
- The machine size and hold to jog on a plain **GRBL** controller (the large router is FluidNC), and a PlayStation-style gamepad.
- A GRBL or FluidNC controller that reports its settings differently, or not at all: the typed-in size is the fallback.
- On Windows: Windows 10, other USB serial adapters, and the SmartScreen warning on a zip downloaded from the internet.
- A long cutting job on a levelled file; the Frame button; grblHAL, GRBL 0.9 and ESP3D boards; machines in inches (`$13`);
  G20 programs; macOS.
- HTTPS: the PIN and the page travel unencrypted on your network. Do not expose DemonX to the internet.

## Known limits

- One shared PIN, no user accounts. A browser that has not signed in cannot press HOLD or RESET either.
- A tunnel to the DemonX computer (an SSH tunnel, `ngrok tcp`) arrives from the computer itself and looks local, so it skips the
  PIN. If you tunnel or forward to DemonX, set a PIN and keep the tunnel private.
- The Windows package is not a Windows service: the computer has to be signed in.
- Remaining job time is an estimate from lines done, rough in the first minute.
- Autolevel refuses relative mode (G91), inches, R-format arcs, G92/G10/G28/G30 and non-XY planes. Rapid G53 moves are allowed.
- The machine outline in the 3D view depends on where the controller puts machine zero. If it looks shifted, type the size in
  at Settings > Machine size and tell us the controller and its homing settings.

## Reporting problems

Open an issue on GitHub with: what you did, what you expected, what happened, the controller (GRBL or FluidNC and its version),
your operating system, and the lines from DemonX's Console or the black window. Screenshots help.
