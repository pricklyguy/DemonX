# DemonX 2.2.2

DemonX controls a machine that can hurt you and wreck work. Keep a hand near the machine's emergency stop and run a new program in
the air first.

**This is the first release published from the public DemonX repository.** The applications are under active development and have
not had extensive testing on real hardware.

DemonX has two parts: **DemonX CNC** (the controller for GRBL / FluidNC machines, with its web page) and **DemonX Design** (drawing,
laser design and CNC toolpaths). This release is a small update on 2.2.1.

## What's new since 2.2.1

- **New default colours (both DemonX and DemonX Design).** The built-in dark and light themes now use a teal accent and cooler,
  blue-grey panels in place of the earlier green and warm tones. Teal is now the first accent preset. Design's drawing area (the
  grid) has its own built-in colour for each theme. Colours you chose yourself in Settings > Appearance are kept; only the built-in
  defaults changed.
- **Rotary setup wording (Design).** The documentation now says plainly that rotary settings (chuck or roller, steps per rotation,
  object size) are saved per laser, and that **running a rotary job is not supported yet**.
- **Public repository.** Source, release notes and the Windows package are now published from `pricklyguy/DemonX`. Update checks
  look at this repository's releases.

No machine-control, G-code or toolpath behaviour was changed in this release.

## Download

| You have | Get |
|---|---|
| Windows 10 or 11 | **`DemonX-2.2.2-windows-x64.zip`** (with its `.sha256` checksum file, which Update now needs). A fresh install: extract to `C:\`, double-click `Start DemonX.bat`, and `Start DemonX Design.bat` for Design. `READ ME FIRST.txt` explains everything. |
| Raspberry Pi | `docs/RASPBERRY-PI.md` in the source; `./scripts/update.sh` (or Update now) updates DemonX, and Design too where it is set up under PM2 |
| Linux or macOS | `docs/LINUX-MAC.md` in the source |

After updating, hard-refresh the browser (Ctrl+Shift+R) so the new colours load. Your `design.env` and `design/data/` stay where they
are. DemonX Design on Windows is a separate window and keeps running the old version until you close it and start it again.

## What has been tested

- DemonX CNC: 431 automated tests passed (2 skipped); DemonX Design: 547 passed. Typecheck and production builds of both applications succeeded.

- **Not tested on hardware.** Simulator tests do not show that a machine will behave safely. Check the first cut of each kind in the
  air, then on scrap.
- Everything listed as not tested on real hardware in the 2.2.1, 2.0.2 and 2.0.1 notes still applies. HTTPS: the PIN and the page
  travel unencrypted on your network. Do not expose DemonX or Design to the internet.
