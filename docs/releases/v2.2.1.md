# DemonX 2.2.1

DemonX controls a machine that can hurt you and wreck work. Keep a hand near the machine's emergency stop and run a new program in
the air first.

**This release changes DemonX Design only (the CNC tab).** DemonX (the CNC controller) is the same as 2.2.0. Design makes G-code
files for you to run; nothing in this release sends a command to a machine by itself. **No toolpath here has been cut on a real
machine, and the new 3D toolpaths least of all.** Run the first one of each kind in the air, slowly, with the emergency stop in reach.

## What's new since 2.2.0 (DemonX Design, CNC tab)

- **The tool library is now a big window** (the fix this release is named for). The Library panel on the right squashed its rows into
  thin lines until a tick was set. It is replaced by a window that fills most of the page: Material and Machine at the top, a search,
  a Millimetres / Inches switch (kept in the browser), the tools listed on the left by maker, and the chosen tool on the right with
  its Geometry (name, kind, diameter, V-bit angle, taper, flutes) and its Cutting parameters for that machine and material (spindle
  speed, feed, plunge, pass depth and stepover, notes). You can add or remove a recipe, add a new tool, delete a tool (it asks twice),
  load a library file and save a copy. Everything you edit is saved to the library at once.
- **Choose a tool from the library in every toolpath.** Each toolpath panel has a "Choose from the library..." button that opens the
  same window as a picker, showing the tools that fit the job's machine and material and the toolpath (a V-bit for V-carving, not a
  drill for engraving), with the best recipe for each. **Use with this recipe** puts the tool in the job with that recipe's numbers;
  you can edit the numbers for one cut while picking.
- **Machine and material for the job.** The Job panel on the CNC tab has Machine and Material choices (from the library's recipes),
  kept in the job.
- **3D shapes from an STL file (new).** Import STL (binary or text, up to 3 million triangles), choose which way is up and
  millimetres or inches, see it shaded, set the width, height and position, and add it to the job as a **relief** (a grid of heights up
  to 800 x 800 cells) drawn shaded on the CNC tab. Up to 8 reliefs per job.
- **3D finishing (new).** A ball nose (or flat or V-bit) follows the relief along X or Y with a stepover and an allowance, using a
  drop cutter. **Add a second pass at right angles** if you want a cross pass.
- **3D roughing (new).** Clears the material level by level, leaving an allowance (0.5 mm to start) for the finishing pass, with
  **Plunge** or **Ramp in along the line** (3 degrees to start, up to 45).
- **Tapered ball noses.** A ball nose can have a taper (the included angle of the cone above the ball) and a largest diameter. The 3D
  toolpaths and the tool dialog use it; the library holds the tapered ones it knows.
- **Saved files.** A file with a relief, a 3D toolpath, a ramp angle, a cross pass or a tapered tool **will not open in an older
  Design**. Older files open unchanged.

After updating, hard-refresh the browser (Ctrl+Shift+R) so the new look and Design's fixes load. Your `design.env` and `design/data/`
stay where they are. DemonX Design on Windows is a separate window and keeps running the old version until you close it and start it
again. On a Raspberry Pi, Update now restarts Design only when it is idle.

## What has been tested

- DemonX's tests (509) and Design's tests, and typecheck for both.
- Design's browser checks against the simulator for the tool database window, the 3D shapes, finishing and roughing, and the older
  Design checks.
- The 3D finishing is tested to stay on or above the surface it works from (to the cell size of the grid), and the roughing never
  below the surface plus its allowance. On a near vertical wall the grid still limits the accuracy to about a quarter of a millimetre.
- **Not tested on hardware. Not one toolpath has been cut**, and the 3D ones have only been looked at in the simulator. Check the
  first cut of each kind in the air, then on scrap.
- **Not done yet:** a scallop height instead of a stepover, finishing only where the surface is steep, a helical ramp in a wide cut,
  lifting to the safe height between cuts, and tracing curved walls to better than the grid.
- Everything listed as not tested on real hardware in the 2.0.2 and 2.0.1 notes still applies. HTTPS: the PIN and the page travel
  unencrypted on your network. Do not expose DemonX or Design to the internet.
