# DemonX 2.0.4

DemonX controls a machine that can hurt you and wreck work. Keep a hand near the machine's emergency stop and run a new program in
the air first.

**This release changes DemonX Design only (drawing tools).** DemonX (the CNC controller) is the same as 2.0.3, and nothing here
sends a command to a machine.

## What's new since 2.0.3 (DemonX Design)

- **Editable text.** Text from the Text tool is now one group with a saved record (the words, font, size, spacing and alignment).
  **Edit text** changes any of them and keeps the text where it is (it follows if you move or scale it). **Text to lines** turns it
  into plain outlines for good. **Text on a curve**: pick the text and a line or outline, press Edit text, then Run along a curve
  (the letters stand on the curve, outside a closed outline by default, with a start offset and an Other side switch; letters
  that would fall past the end of an open curve are dropped and counted). Duplicate, Array and Copy to layer keep the copies
  editable. Design files gain an optional list of texts; old files open unchanged.
- **Measure tool (M).** Click two points or drag; it snaps to the grid and to shape points. It shows the distance, across, up and
  angle on the drawing and in a card, in mm and inches. It adds nothing to the drawing.
- **Arrow keys move the selection.** The step follows the zoom as in VCarve (about 3 screen pixels, rounded to 1, 2 or 5 times a power
  of ten); **Shift** is ten times, **Alt** a tenth. Off while you are typing in a box, with nothing picked, and in the Nodes tool.
- **Fixed:** while drawing a circle, polygon, star or arc, the size shown next to the cursor said `r` even when Diameter was chosen;
  it now follows your choice.
- **Also in 2.0.3, but not in its notes** (they were merged just before 2.0.3 was built, and its notes said they were not in it):
  the **Align and space** card (to the material, the selection or the first one picked; left, centre, right, top, bottom; spacing
  evenly or by a typed gap; a group now counts as one object) and the **Move and resize** card (move by a distance; resize in mm or
  percent from a chosen point, with X and Y linked or apart). The polygon tool is now called "Regular polygon" to tell it from
  Polygon / line.
- Not in this release: fillet, extend, fit curves, Boundary Create, bitmap trace, a vector validator, and double-click to edit text.

## Download

| You have | Get |
|---|---|
| Windows 10 or 11 | **`DemonX-2.0.4-windows-x64.zip`** (below, with its `.sha256` checksum file, which Update now needs), or Update now from 2.0.1 or later if you turned it on. A fresh install: extract to `C:\`, double-click `Start DemonX.bat`, and `Start DemonX Design.bat` for Design. `READ ME FIRST.txt` explains everything. |
| Raspberry Pi | `docs/RASPBERRY-PI.md` in the source; `./scripts/update.sh` (or Update now) updates DemonX, and Design too where it is set up under PM2 |
| Linux or macOS | `docs/LINUX-MAC.md` in the source |

After updating, hard-refresh the browser (Ctrl+Shift+R) so Design's new tools load. Your `design.env` and `design/data/` stay where
they are. DemonX Design on Windows is a separate window and keeps running the old version until you close it and start it again.
On a Raspberry Pi, Update now restarts Design only when it is idle.

## What has been tested

- Design's tests (419) and its browser checks for editable text, Measure and the arrow keys, plus the tool bar, shapes, align, move
  and resize, tabs, menus and the main Design check, all against the simulator.
- **Not tested on hardware: this release is drawing-side only.** Nothing in it sends a command to a machine.
- The main Design browser check (`design/e2e/design.mjs`), which had been failing at its GRBL Pause step since Design was first
  added, was a mistake in the check itself (it added a shape to a layer before the layer existed, so the "long job" it meant to
  pause never ran). That is fixed and the check passes. It does not change how Pause works.
- Everything listed as not tested on real hardware in the 2.0.2 and 2.0.1 notes still applies (the Laser tab's new moves, Home, Z and
  Auto focus, Pause and Resume, the Windows updater and package, and the rest). HTTPS: the PIN and the page travel unencrypted on
  your network. Do not expose DemonX or Design to the internet.
