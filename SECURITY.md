# Security

DemonX controls machines that can injure people. A security problem (for example a way for someone on the network to move a machine
without the PIN, or to read the PIN or a saved password) is a safety problem.

**Please do not open a public issue for one.** Report it privately: on the repository's **Security** tab choose **Report a
vulnerability**. Say which version you use, what you did, and what happened. You will get an answer as soon as it can be given.

What helps: the version (shown in the screen's header and in `package.json`), how DemonX is installed (Windows package, Raspberry Pi,
Docker), and whether the PIN was set. Please do not include your own PIN, saved passwords, camera or Home Assistant tokens, or
network addresses you want to keep private.

DemonX is meant for a trusted home or shop network. It is not built to be exposed to the internet, and reports that depend on doing
so are answered with advice to put it behind a VPN instead.
