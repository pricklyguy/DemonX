# DemonX 2.0.1

DemonX controls a machine that can hurt you and wreck work. Keep a hand near the machine's emergency stop and run a new program in
the air first.

## What's new since 2.0.0

- **Update now for the Windows package** (**Settings > Updates > Allow Update now on this page**, off until you turn it on).
  A signed-in browser can install the release on offer: DemonX downloads that release's Windows zip from GitHub, checks it against
  the checksum published with it, unpacks it **next to** the version you run, and restarts itself into the new one when the
  machine is idle (not while a job, probe or move is going on). Nothing that is running is replaced, your settings stay where
  they are, and if the new version does not start, DemonX puts the old one back by itself and tells you. DemonX has to be started
  with `Start DemonX.bat` (it is what starts DemonX again after an update). DemonX Design is a separate window and keeps running
  the old version until you close it and start it again.
- **The Windows folder is laid out differently** to make that possible: each version is in `C:\DemonX\versions\<version>`, and
  `current.txt` says which one runs. The start files now start DemonX through `launcher.mjs`. Your `data` folder is not touched.
- **The update box now says why Update now is not available** (for example "turned off: turn it on in Settings > Updates"), writes
  out what to do by hand, and no longer has an "Update" button that only opened the release page (there is a "Release page" button).

## Download

| You have | Get |
|---|---|
| Windows 10 or 11 | **`DemonX-2.0.1-windows-x64.zip`** (below, with its `.sha256` checksum file, which Update now needs). Extract to `C:\` (it makes `C:\DemonX`; extracting over an older one keeps your settings), double-click `Start DemonX.bat`, and `Start DemonX Design.bat` for Design. `READ ME FIRST.txt` explains everything. |
| Raspberry Pi | `docs/RASPBERRY-PI.md` in the source |
| Linux or macOS | `docs/LINUX-MAC.md` in the source |

**Updating from 2.0.0 or older on Windows: do it by hand this one time.** Those versions have no updater, and this release changes the
folder layout. Close DemonX and DemonX Design, extract the zip over `C:\DemonX` as above, and start `Start DemonX.bat`. The first
start prints "Removed the old app folder" (the old layout's `app` folder is not used any more). From this release on, Update now
works. Hard-refresh the browser afterwards (Ctrl+Shift+R). Raspberry Pi and Linux installs are not affected (`./scripts/update.sh`,
or Update now).

## What has been tested on real machines

By the project owner:

- **Update now on a Raspberry Pi** (a git install run by PM2): it installed a newer release and restarted DemonX.
- **DemonX Design with a Ruida laser** (an OMTech Pronto 45): jobs (cut and engrave, with air), jogs, frames and Stop.
- Everything from the 2.0.0 and earlier notes.

## What has not been tested on real hardware

- **The Windows updater has never been run on Windows.** It was built and tested on Linux (the launcher run as a real program
  against throwaway installs, and the updater against a local server and real zip files, including a new version that crashes
  and is put back). Not tried: the rewritten `.bat` files, `tar.exe` unpacking the zip, Windows file locking and antivirus, and a
  real GitHub release. **Nobody can update to 2.0.1 with it**, because versions before it have no updater: the first real
  Windows update will be from 2.0.1 to the next release, so please be at the PC, with the machine idle, the first time.
- The Windows package itself has not been run on Windows 10 or 11 since this layout change (including the SmartScreen warning on
  a zip downloaded from the internet).
- The checksum guards against a damaged or incomplete download. It comes from the same release, so it cannot protect against a
  release that was itself replaced. Downloads are not signed.
- That Update now also updated and restarted DemonX Design on the Pi was not checked; the busy refusals (a job or laser job running
  when the update is started) were checked with stand-in programs and tests only.
- Parts of Design beyond the Ruida laser on the owner's machine, and everything listed as untested in the 2.0.0 and earlier notes
  (see `design/README.md`).
- HTTPS: the PIN and the page travel unencrypted on your network. Do not expose DemonX or Design to the internet.
